# 素材库查重

> 篝火出品 · 收录于篝火 App 应用区

扫描图片文件夹，找出完全相同和近似重复的图片，移到「待删除」

![界面截图](docs/screenshot.png)

## 下载

到 [Releases](https://github.com/campfire-code/asset-dedup/releases/latest) 下载对应安装包：

| 电脑 | 文件 |
|---|---|
| Windows 10 / 11 | `asset-dedup_版本号_windows-x64-setup.exe` |
| Mac（Apple 芯片） | `asset-dedup_版本号_mac-arm64.dmg` |
| Mac（Intel 芯片） | `asset-dedup_版本号_mac-x64.dmg` |

第一次打开：
- **Windows**：如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
- **Mac**：如果提示「无法验证开发者」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」。

## 怎么用

**只支持图片**（JPG、JPEG、PNG、WebP、BMP、GIF），**暂不支持视频**；文件夹里的其他文件会被跳过。

1. 点「选择文件夹」，或把文件夹、图片直接拖进窗口（可以加多个）。
2. 拖动「相似度阈值」：默认 6（标准，缩放、压缩、轻微调色也能找到）；调到 0 只找画面完全一样的，调大更宽松但误判变多。扫描完再拖动，会直接重新分组，不用重扫。
3. 点「开始查重」。工具把每张图缩成 32×32 的灰度图算出指纹，同时算文件内容指纹：内容一样的归为「完全相同」，指纹接近的归为「近似」。名叫「待删除」的文件夹会被跳过。
4. 看结果：顶部大字是移走后可释放的空间，下面每一组左边是保留的大图，右边是将被移走的图和相似度。默认保留分辨率最高的一张（分辨率一样取文件更大的，再一样取文件名更短的），点右边任意一张可改成保留它；不想动的组点「这组不处理」。
5. 点「把重复项移到「待删除」」，再点「确认移动」。重复项被**移动**到扫描文件夹下的「待删除」文件夹，不会删除任何文件，同名文件会自动改名为「名字 (2)」；文件夹里还会写一份「移动清单-日期时间.txt」，记录每个文件的原位置，方便放回。确认无误后请自己清理。

读不了的图片（损坏或格式不支持）会在顶部提示「N 张读取失败」，点开可看原因并在文件夹中定位。

**注意**：近似判断是按画面指纹估算，构图相近的不同图可能被归到一起，移走前请先看分组；纯色图只按完全相同判断；全部在本机完成，不联网、不上传。

## 验收用例

示例文件在 `samples/示例素材库/`（程序画的几何图形，共 12 个文件，含 `旧素材` 子文件夹）。

| 操作 | 应得到 |
|---|---|
| 选择 `samples/示例素材库`，阈值保持 6，点「开始查重」 | 共扫描 11 张；顶部显示「5 张重复图 · 2 组」；另提示「1 张读取失败」，点开是 `示例-损坏.jpg` |
| 看第 1 组 | 标「完全相同」，3 张：保留 `示例-山景.png`，将移走 `示例-山景-副本.png` 和 `旧素材/示例-山景-再存一份.png` |
| 看第 2 组 | 标「近似」，4 张：`示例-日落.png`、`示例-日落-缩小.png`、`示例-日落-调暗.png`、`示例-日落-加角标.png`；默认保留文件最大的 `示例-日落-加角标.png`（四张里它分辨率并列最高、文件最大） |
| 点第 2 组右边的 `示例-日落.png` | 它变成保留项，原来保留的 `示例-日落-加角标.png` 出现在右边 |
| 勾选第 2 组的「这组不处理」 | 顶部的可移走张数从 5 张变成 2 张 |
| 点「把重复项移到「待删除」」→「确认移动」 | 提示已移动，没有删除任何文件；`示例素材库/待删除/` 里出现被移走的图和「移动清单-….txt」；`旧素材/` 里的那张也被移到根目录的「待删除」里 |
| 再对同一文件夹查重 | 「待删除」里的文件不再参与扫描；山景只剩 1 张，不再成组；日落 4 张已被移走 3 张，也不再成组 |

开发自检：`pnpm test` 里有「示例图按预期分成两组」的用例，对应上面的分组结果。

## 自己编译

需要 Node.js 22、pnpm、Rust。

```bash
pnpm install
pnpm test          # 单元测试
pnpm tauri dev     # 开发运行
pnpm tauri build   # 打包
```

界面框架在 `src/kit`（所有 campfire-code 工具共用），本工具的逻辑在 `src/tool`。
